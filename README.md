## About

I'm Karen Ojeda, a UX/UI Designer based in Culiacán, Sinaloa (México). This repo holds the source for my personal site — where I show my work, share a bit about how I think about design, and point people to my resume and socials.

No frameworks, no build step. Just HTML, CSS, and vanilla JS, built and deployed by hand.

## Tech stack

- **HTML5 / CSS3 / JavaScript** — no framework, no bundler
- **Google Fonts** — Bebas Neue (display) + DM Sans (body)
- **Hosting** — [Hostinger](https://hostinger.com), proxied through [Cloudflare](https://cloudflare.com)
